  <section class="space-y-4">
    <SectionHeading id="hyprctl-overview">
      Overview of hyprctl
    </SectionHeading>
    <p>
      <strong class="text-white">hyprctl</strong> is the official command-line control and IPC interface for <strong class="text-[#299C45]">Hyprland</strong>. It allows you to trigger compositor actions, query internal state in structured JSON, dynamically adjust appearance keywords at runtime, and build custom desktop scripts.
    </p>

```bash
# Standard invocation
hyprctl [options] <command> [args]

# Output pure JSON for shell scripting
hyprctl -j <command>
```
  </section>

  <section class="space-y-4">
    <SectionHeading id="ipc-socket-scripting">
      IPC Event Socket Scripting
    </SectionHeading>
    <p>
      Hyprland exposes UNIX domain sockets under <code class="text-white font-mono">$XDG_RUNTIME_DIR/hypr/$HYPRLAND_INSTANCE_SIGNATURE/</code> for streaming compositor events in real time (e.g. workspace changes, window focus, monitor connect):
    </p>

```bash
# Stream live events directly using socat
SOCKET="$XDG_RUNTIME_DIR/hypr/$HYPRLAND_INSTANCE_SIGNATURE/.socket2.sock"
socat -U - UNIX-CONNECT:"$SOCKET" | while read -r line; do
  echo "Event received: $line"
done
```
