      Hyprland Wayland Compositor
    </SectionHeading>
    <p>
      Hyprland is a dynamic tiling Wayland compositor that does not sacrifice on appearance. It provides fluid animations, rounded corners, dual-borders, and advanced multi-monitor workspaces.
    </p>
  </section>

  <section class="space-y-4">
    <SectionHeading id="config-architecture">
      Nitro OS Configuration Layout
    </SectionHeading>
    <p>
      Configurations are located in <code class="text-[#299C45] font-mono">~/.config/hypr/</code>:
    </p>

```text
~/.config/hypr/
├── hyprland.conf            # Main entrypoint
├── nitro/
│   ├── keybindings.lua     # App shortcuts & key bindings
│   ├── windowrules.conf    # Window floating & opacity rules
│   └── monitors.conf       # Display resolutions & scaling
└── scripts/                # Utility shell scripts
```
