    <SectionHeading id="system-requirements">
      System Requirements
    </SectionHeading>
    <p>
      Nitro OS is optimized for modern x86_64 architecture machines with UEFI firmware. Ensure your target machine meets these specifications:
    </p>
    <div class="grid sm:grid-cols-2 gap-4">
      <Card class="space-y-4">
        <div class="pb-2 border-b border-border/50">
          <h3 class="text-xs uppercase tracking-wider text-text-muted font-semibold font-mono">Minimum Specs</h3>
        </div>
        <ul class="space-y-2.5 text-sm text-text-muted font-sans">
          <li><strong class="text-text font-medium">CPU:</strong> 64-bit Dual-Core (x86_64)</li>
          <li><strong class="text-text font-medium">RAM:</strong> 2 GB (4 GB recommended)</li>
          <li><strong class="text-text font-medium">Storage:</strong> 20 GB NVMe / SSD / HDD</li>
          <li><strong class="text-text font-medium">Graphics:</strong> OpenGL 3.3+ or Vulkan GPU</li>
          <li><strong class="text-text font-medium">Firmware:</strong> UEFI Boot Support</li>
        </ul>
      </Card>

      <Card class="space-y-4">
        <div class="pb-2 border-b border-border/50">
          <h3 class="text-xs uppercase tracking-wider text-[#299C45] font-semibold font-mono">Recommended Specs</h3>
        </div>
        <ul class="space-y-2.5 text-sm text-text-muted font-sans">
          <li><strong class="text-text font-medium">CPU:</strong> 4+ Cores Intel / AMD Ryzen</li>
          <li><strong class="text-text font-medium">RAM:</strong> 8 GB+ High-Speed Memory</li>
          <li><strong class="text-text font-medium">Storage:</strong> 50 GB+ NVMe SSD</li>
          <li><strong class="text-text font-medium">Graphics:</strong> AMD Radeon, Intel Arc, or Nvidia</li>
          <li><strong class="text-text font-medium">Network:</strong> Active Internet Connection</li>
        </ul>
      </Card>
    </div>
  </section>

  <section class="space-y-4">
    <SectionHeading id="download-iso">
      Download &amp; Flash ISO
    </SectionHeading>
    <p>
      Download the latest release ISO image or obtain it directly from the download mirror. Verify SHA256 checksums and flash to a USB flash drive:
    </p>

    <div class="p-4 rounded-xl bg-surface/60 border border-border flex flex-col sm:flex-row items-start sm:items-center justify-between gap-4">
      <div>
        <h4 class="text-sm font-semibold text-text">Nitro OS Latest ISO (x86_64)</h4>
        <p class="text-xs text-text-dim mt-0.5">Direct ISO image download ready for USB flashing</p>
      </div>
      <a 
        href="https://drive.google.com/uc?export=download&id=1JimgDkKyEdvYtg8S6cyOxs3KPt5vRohp" 
        class="inline-flex items-center gap-2 px-4 py-2 rounded-lg bg-[#299C45] hover:bg-[#217D37] text-white text-xs font-semibold font-mono transition-all shadow-sm shrink-0"
      >
        <Download class="w-4 h-4" />
        Direct Download ISO
      </a>
    </div>

```bash
# Verify ISO Checksum
sha256sum nitro-os-latest-x86_64.iso

# Flash via dd (Replace /dev/sdX with your actual USB drive)
sudo dd if=nitro-os-latest-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync
```
  </section>

  <section class="space-y-4">
    <SectionHeading id="live-boot">
      Booting Live Environment
    </SectionHeading>
    <p>
      Insert the USB drive, enter your system BIOS/UEFI boot menu (typically <Kbd>F12</Kbd>, <Kbd>F11</Kbd>, or <Kbd>Del</Kbd>), disable Secure Boot, and boot into the live environment.
    </p>
  </section>

  <section class="space-y-4">
    <SectionHeading id="installer-wizard">
      Running Nitro Installer
    </SectionHeading>
    <p>
      Once inside the live desktop session, press <KeyCombo keys={["SUPER", "Space"]} /> to open the application launcher, then search for and launch <strong class="text-white">Install NitroOS</strong> to start the graphical installer.
    </p>
    <p>
      The installer handles everything automatically:
    </p>
    <ul class="list-disc pl-5 space-y-2 text-text-muted">
      <li><strong class="text-text font-medium">Disk Partitioning:</strong> Automated whole-disk partitioning and file system setup (as well as custom manual layout options) are built directly into the GUI installer.</li>
      <li><strong class="text-text font-medium">Automatic Reboot:</strong> Once installation completes, the installer offers an automatic reboot into your new Nitro OS installation (remove the USB drive when prompted).</li>
    </ul>
  </section>
