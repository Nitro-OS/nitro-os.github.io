  <section class="space-y-4">
    <SectionHeading id="what-is-nitro-os">
      What is Nitro OS?
    </SectionHeading>
    <p>
      <strong class="text-text">Nitro OS</strong> is a modern, minimal, high-performance Linux distribution engineered for developers, power users, and system minimalists. It combines an accelerated Wayland desktop environment powered by <strong class="text-[#299C45]">Hyprland</strong> with a developer toolkit featuring <strong class="text-text">NitroVim</strong>, <strong class="text-text">NitroPkg (npk)</strong>, and <strong class="text-text">NitroHttp</strong>.
    </p>
  </section>

  <section class="space-y-4">
    <SectionHeading id="core-philosophy">
      Core Philosophy
    </SectionHeading>
    <div class="grid sm:grid-cols-2 gap-4">
      <Card class="space-y-2">
        <h3 class="text-base font-bold text-[#299C45] flex items-center gap-2">Speed First</h3>
        <p class="text-xs text-text-dim leading-relaxed">Sub-second app launches, instant terminal responsiveness, and ultra-lean baseline RAM usage (~900MB on cold boot).</p>
      </Card>
      <Card class="space-y-2">
        <h3 class="text-base font-bold text-[#299C45] flex items-center gap-2">Wayland Native</h3>
        <p class="text-xs text-text-dim leading-relaxed">Silky 144Hz/240Hz tear-free compositor, smooth Bézier curves, and dual-kawase blur algorithms with minimal GPU overhead.</p>
      </Card>
      <Card class="space-y-2">
        <h3 class="text-base font-bold text-[#299C45] flex items-center gap-2">NitroPkg (npk)</h3>
        <p class="text-xs text-text-dim leading-relaxed">High-performance Rust-powered package manager for streamlined installation, system upgrades, and cache maintenance.</p>
      </Card>
      <Card class="space-y-2">
        <h3 class="text-base font-bold text-[#299C45] flex items-center gap-2">Human-Readable Configs</h3>
        <p class="text-xs text-text-dim leading-relaxed">Every dotfile in ~/.config/ is cleanly organized in Lua, documented, and ready for version control.</p>
      </Card>
    </div>
  </section>

  <section class="space-y-4">
    <SectionHeading id="key-features">
      Key Features at a Glance
    </SectionHeading>
    <ul class="space-y-2.5 list-disc pl-5 text-text-muted">
      <li><strong class="text-text">Out-of-the-Box Polish:</strong> Fully configured Waybar status bar, Rofi application menu, and wallpaper management.</li>
      <li><strong class="text-text">Fastest Modal Editor:</strong> Pre-installed NitroVim with Treesitter, Lua snippets, and Mason LSP pre-wired.</li>
      <li><strong class="text-text">Gaming &amp; Graphics Ready:</strong> Mesa drivers for AMD/Intel Vulkan acceleration, plus dedicated Nvidia Wayland driver profiles.</li>
      <li><strong class="text-text">Rolling-Release Stability:</strong> Up-to-date Arch Linux base with the latest Linux kernel and PipeWire audio stack.</li>
    </ul>
  </section>
