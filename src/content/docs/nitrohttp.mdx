      Overview &amp; Subcommands
    </SectionHeading>
    <p>
      <strong class="text-text">NitroHttp CLI (<code class="text-[#299C45]">nhttp</code>)</strong> is the command-line companion to NitroHttp. It is a blazing-fast HTTP testing tool for rapid API validation directly from the terminal, featuring syntax-highlighted JSON rendering, structured table views, and rich response statistics.
    </p>

  <section class="space-y-4">
    <SectionHeading id="installation">
      Installation &amp; Verification
    </SectionHeading>
    <p>
      NitroHttp is pre-installed on Nitro OS. You can also install or update it as a global .NET tool or compile it with Native AOT for instant sub-millisecond execution:
    </p>

```bash
# Install via .NET Tool
dotnet tool install -g NitroHttp

# Verify installation & view help
nhttp --help

# Update to the latest release
dotnet tool update -g NitroHttp

# Uninstall if needed
dotnet tool uninstall -g NitroHttp
```
  </section>

  <section class="space-y-4">
    <SectionHeading id="general-usage">
      General Usage &amp; Syntax Rules
    </SectionHeading>
    <p>The standard invocation syntax for all commands:</p>
    
```bash
nhttp <command> --url <endpoint> [--body <json-or-file>]
```

    <div class="grid sm:grid-cols-2 gap-4">
      <Card class="space-y-1.5">
        <h4 class="text-xs font-semibold text-[#299C45] font-mono uppercase tracking-wider">--url is required</h4>
        <p class="text-xs text-text-dim leading-relaxed font-sans">Every command requires a target URL. If no protocol is provided, https:// is automatically prepended.</p>
      </Card>
      <Card class="space-y-1.5">
        <h4 class="text-xs font-semibold text-[#299C45] font-mono uppercase tracking-wider">--body for payloads</h4>
        <p class="text-xs text-text-dim leading-relaxed font-sans">Required for post, put, and patch. Sent as application/json automatically.</p>
      </Card>
      <Card class="space-y-1.5">
        <h4 class="text-xs font-semibold text-[#299C45] font-mono uppercase tracking-wider">Automatic file reading</h4>
        <p class="text-xs text-text-dim leading-relaxed font-sans">If --body points to an existing file path (e.g. ./payload.json), nhttp reads and transmits file contents.</p>
      </Card>
      <Card class="space-y-1.5">
        <h4 class="text-xs font-semibold text-[#299C45] font-mono uppercase tracking-wider">Stats panel</h4>
        <p class="text-xs text-text-dim leading-relaxed font-sans">Displays HTTP status code, response time in ms, payload byte size, and array/object item counts.</p>
      </Card>
    </div>
  </section>

  <section class="space-y-4">
    <SectionHeading id="get-requests">
      GET Requests &amp; JSON Rendering
    </SectionHeading>
    <p>
      Fetch endpoints with automatic formatted JSON tables and timing statistics:
    </p>

```bash
# Standard GET command
nhttp get --url https://jsonplaceholder.typicode.com/users

# Using short alias and implicit https://
nhttp g --url jsonplaceholder.typicode.com/posts
```
  </section>

  <section class="space-y-4">
    <SectionHeading id="post-put-patch">
      POST, PUT &amp; PATCH with Inline/File Payloads
    </SectionHeading>
    <p>
      Transmit payloads using either inline JSON strings or existing local JSON file paths:
    </p>

```bash
# POST with inline JSON string
nhttp post --url https://jsonplaceholder.typicode.com/users --body '{"name":"Ada Lovelace"}'

# POST with JSON file payload
nhttp p --url jsonplaceholder.typicode.com/users --body ./payloads/user.json

# PUT full update
nhttp put --url https://jsonplaceholder.typicode.com/users/42 --body ./payloads/user-update.json

# PATCH partial update
nhttp patch --url https://jsonplaceholder.typicode.com/users/42 --body '{"title":"Lead Systems Engineer"}'
```
  </section>

  <section class="space-y-4">
    <SectionHeading id="delete-requests">
      DELETE Requests
    </SectionHeading>
    <p>Remove remote records and inspect status codes:</p>

```bash
# Standard DELETE
nhttp delete --url https://jsonplaceholder.typicode.com/users/42

# Using short alias
nhttp del --url jsonplaceholder.typicode.com/posts/10
```
  </section>

  <section class="space-y-4">

      Response Output &amp; Stats Panel
    </SectionHeading>

    </p>
    <ul class="space-y-2 list-disc pl-5 text-sm text-text-muted">

      <li><strong class="text-text">Item Count:</strong> Automatic length detection for JSON arrays and object collections.</li>
