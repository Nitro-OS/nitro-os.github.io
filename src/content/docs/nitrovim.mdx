    <SectionHeading id="overview">
      NitroVim Overview &amp; Quickstart
    </SectionHeading>
    <p>
      <strong class="text-white">NitroVim</strong> is the official modal code editor for <strong class="text-[#299C45]">Nitro OS</strong>. Engineered on top of Neovim with Lua, it delivers sub-millisecond startup, Treesitter syntax parsing, Mason LSP tooling, AI assistance with GitHub Copilot, and native Git workflow integration.
    </p>

    <div class="grid sm:grid-cols-2 gap-4">
      <Card class="space-y-1.5">
        <h4 class="text-xs font-semibold text-[#299C45] font-mono uppercase tracking-wider">Leader Key</h4>
        <p class="text-xs text-text-dim leading-relaxed font-sans">
          The global leader key is configured to <Kbd>Space</Kbd>. All custom commands and menu toggles chain from Space.
        </p>
      </Card>

      <Card class="space-y-1.5">
        <h4 class="text-xs font-semibold text-[#299C45] font-mono uppercase tracking-wider">Interactive Learning</h4>
        <p class="text-xs text-text-dim leading-relaxed font-sans">
          Launch <code class="text-white font-mono">:NitroLearn</code> inside the editor anytime for interactive motion drills and keymap guides.
        </p>
      </Card>
    </div>

```bash
# Launch NitroVim
nvim

# Open a specific file or folder
nvim ./src/main.rs
```

      Customization &amp; Adding Lua Plugins
    </SectionHeading>
    <p>
      NitroVim configurations are located in <code class="text-white font-mono">~/.config/nvim/</code>. You can customize options, keymaps, and install community plugins using the declarative Lua structure:
    </p>

    <div class="space-y-3">
      <h3 class="text-sm font-semibold text-white font-mono uppercase tracking-wide">Adding a Plugin in lua/nitro/plugins/plugins.lua</h3>

```lua
return {
  {
    "folke/which-key.nvim",
    event = "VeryLazy",
    opts = {
    },
  },
}
```
    </div>

    <div class="space-y-3">
      <h3 class="text-sm font-semibold text-white font-mono uppercase tracking-wide">Enabling New LSP Servers in lua/nitro/lsp/lsp.lua</h3>

```lua
local servers = { "rust_analyzer", "gopls", "pyright", "ts_ls", "clangd", "lua_ls" }

for _, server in ipairs(servers) do
  lspconfig[server].setup({
    capabilities = capabilities,
    on_attach = on_attach,
  })
end
```
