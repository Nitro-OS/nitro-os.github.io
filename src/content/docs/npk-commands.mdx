  <section class="space-y-4">
    <SectionHeading id="npk-install">
      npk install / npk i (Install Packages)
    </SectionHeading>
    <p>
      Downloads and installs one or more packages from the configured Nitro OS repositories along with all required dependencies:
    </p>

```bash
# Install a single package using full command
npk install firefox

# Install using short alias 'i'
npk i neovim

# Install multiple packages in a single transaction
npk i git curl ripgrep fzf zsh

# Non-interactive confirmation mode
npk i alacritty -y
```
  </section>

  <section class="space-y-4">
    <SectionHeading id="npk-remove">
      npk remove / npk rm (Remove Packages)
    </SectionHeading>
    <p>
      Safely removes installed packages from your Nitro OS system, with dependency checking to prevent breaking other active packages:
    </p>

```bash
# Remove a package using full command
npk remove firefox

# Remove using short alias 'rm'
npk rm vlc

# Remove package and clean unneeded orphaned dependencies
npk rm thunar --autoremove
```
  </section>

  <section class="space-y-4">
    <SectionHeading id="npk-search">
      npk search / npk s (Search Packages)
    </SectionHeading>
    <p>
      Searches all configured official repositories and mirrors for package names, keywords, and descriptions:
    </p>

```bash
# Search packages by name or keyword
npk search waybar

# Search using short alias 's'
npk s rust

# Filter exact matches only
npk s --exact hyprland
```
  </section>

  <section class="space-y-4">
    <SectionHeading id="npk-update">
      npk update (Sync Database)
    </SectionHeading>
    <p>
      Refreshes and synchronizes local package metadata databases against active Nitro OS repository mirrors:
    </p>

```bash
# Synchronize package databases
npk update

# Force refresh package databases
npk update --refresh
```
  </section>

  <section class="space-y-4">
    <SectionHeading id="npk-upgrade">
      npk upgrade (System &amp; Package Upgrades)
    </SectionHeading>
    <p>
      Upgrades all installed packages across your Nitro OS installation to their latest available repository versions:
    </p>

```bash
# Perform full system rolling upgrade
npk upgrade

# Non-interactive upgrade with auto-confirm
npk upgrade -y

# Preview package upgrade changes without modifying system
npk upgrade --dry-run
```
  </section>

  <section class="space-y-4">
    <SectionHeading id="npk-clean">
      npk clean (Clean Cache)
    </SectionHeading>
    <p>
      Frees disk space by removing obsolete downloaded package archives and build caches:
    </p>

```bash
# Clean old package cache archives
npk clean

# Thoroughly purge entire cache directory
npk clean --all
```
  </section>

  <section class="space-y-4">
    <SectionHeading id="npk-list">
      npk list (List Installed Packages)
    </SectionHeading>
    <p>
      Inspects local package state, listing installed software, explicitly installed binaries, and orphaned packages:
    </p>

```bash
# List all installed packages
npk list --installed

# List orphan packages no longer required by any installed application
npk list --orphans
```
  </section>
