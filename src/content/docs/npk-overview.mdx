    <SectionHeading id="what-is-npk">
      What is NitroPkg (npk)?
    </SectionHeading>
    <p>
      <strong class="text-text">NitroPkg (npk)</strong> is the official package manager for <strong class="text-white">Nitro OS</strong>. Engineered in <strong class="text-[#299C45]">Rust</strong>, it provides a fast, lightweight, and user-friendly command-line interface for installing, removing, updating, and managing system software.
    </p>
  </section>

    <SectionHeading id="installation-verification">
      Installation &amp; Verification
    </SectionHeading>
    <p>
      NitroPkg comes pre-installed with Nitro OS. You can verify your installed version directly from any terminal:
    </p>

```bash
# Check npk version
npk --version

# View all available flags and help
npk --help
```
  </section>
